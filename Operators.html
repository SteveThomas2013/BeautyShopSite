Bitwise Operators
Bitwise AND (&): Performs a bitwise AND operation on each pair of corresponding bits.
Bitwise OR (|): Performs a bitwise OR operation on each pair of corresponding bits.
Assignment Operators
Assignment (=): Assigns the value on the right to the variable on the left.
Addition Assignment (+=): Adds the value on the right to the current value of the variable on the left.
Subtraction Assignment (-=): Subtracts the value on the right from the current value of the variable on the left.
Multiplication Assignment (*=): Multiplies the current value of the variable on the left by the value on the right.
Division Assignment (/=): Divides the current value of the variable on the left by the value on the right.
